# 運作前準備

此專案為server-client端程式，運行前須開啟伺服器

1. 開啟main.py伺服器端程式(F5執行)
2. 開啟ngrok端口對應
   - 開啟cmd
   - 輸入指令ngrok http 1202
3. 執行
   ```
   npm run dev
   ```
